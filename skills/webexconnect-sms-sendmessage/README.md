# webexconnect sms sendmessage

Standalone Webex Connect agent skill: webexconnect sms sendmessage.

## Install

Install from this skill's latest GitHub release package; it is not published to npm. To pin a version, replace `latest` with the desired version.

```sh
npx --yes \
  --package https://raw.githubusercontent.com/webex/webex-skills/main/skills/webexconnect-sms-sendmessage/release/webexconnect-sms-sendmessage-latest.tgz \
  webexconnect-sms-sendmessage install --client codex --scope user
```

Use `--scope project` to install into the current project, or `--client all` to install for Codex, GitHub Copilot, and Claude Code. Add `--force` only when replacing an existing installation.
