# webexconnect digital asset creation

Standalone Webex Connect agent skill: webexconnect digital asset creation.

## Install

`npx webexconnect-digital-asset-creation install --client codex --scope user` installs this skill for your user account. Use `--scope project` to install it into the current project, or `--client all` to install for Codex, GitHub Copilot, and Claude Code. Add `--force` only when replacing an existing installation.
