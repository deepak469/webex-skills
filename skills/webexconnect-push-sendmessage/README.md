# webexconnect push sendmessage

Standalone Webex Connect agent skill: webexconnect push sendmessage.

## Install

`npx webexconnect-push-sendmessage install --client codex --scope user` installs this skill for your user account. Use `--scope project` to install it into the current project, or `--client all` to install for Codex, GitHub Copilot, and Claude Code. Add `--force` only when replacing an existing installation.
