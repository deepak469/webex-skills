# webex connect setup

Standalone Webex Connect agent skill: webex connect setup.

## Install

`npx webex-connect-setup install --client codex --scope user` installs this skill for your user account. Use `--scope project` to install it into the current project, or `--client all` to install for Codex, GitHub Copilot, and Claude Code. Add `--force` only when replacing an existing installation.
